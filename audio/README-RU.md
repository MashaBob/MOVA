# Папка audio

Здесь хранятся MP3 с женским произношением русских слов и фраз для уроков MOVA.

Название файла должно быть коротким и понятным: например privet.mp3 или kak-tebya-zovut.mp3.

Чтобы добавить новую озвучку, загрузи MP3 сюда, затем подключи его в app-v41.js рядом с нужным словом или упражнением.
